## 🧠 Messenger Text Tool by SelfCode

<img width="452" height="589" alt="image" src="https://github.com/user-attachments/assets/49bda678-a8c7-495e-880f-a47dce0b2694" />


✨ **Messenger Text Tool (MTT)** — это стильное и удобное приложение, созданное для тех, кто хочет быстро и красиво форматировать текст под **WhatsApp** и **Telegram**.
Программа превращает обычный текст в идеально оформленные сообщения, используя фирменные стили каждого мессенджера.

### ⚙️ Возможности

💬 Преобразование текста в форматы:

* **WhatsApp** — жирный, курсив, зачёркнутый, цитаты, код и моноширинные блоки
* **Telegram** — жирный, курсив, зачёркнутый, код, моноширинный и скрытый текст

🌈 Дополнительно:

* Мгновенное обновление результата при вводе
* Копирование готового текста одним нажатием
* Автоматическое применение и отмена эффектов при изменении чекбоксов
* Анимированные уведомления о копировании
* Красивый фирменный интерфейс с плавными эффектами от **SelfCode**

### 🖥️ Поддерживаемые ОС

✅ **Windows 10 / 11 (x64)**

### 📦 Как использовать

1. Скачайте и запустите **MTT.exe**
2. Выберите мессенджер — **WhatsApp** или **Telegram**
3. Введите свой текст в верхнее поле
4. Отметьте нужные стили (жирный, курсив, код и т.д.)
5. Скопируйте результат кнопкой **«Скопировать результат»**
6. Вставьте в нужный чат — готово! 🎯

---

### 🧾 Пример

Ввод:

```
Привет, как дела?
```

Результат (для Telegram, при выборе жирного и курсивного):

```
**__Привет, как дела?__**
```
